# BestHouse.uz — Агрегатор и интерактивная карта недвижимости Ташкента

Интерактивная карта недвижимости Ташкента на **Leaflet 1.9 + Leaflet.markercluster**, объединённая с ведущими площадками недвижимости Узбекистана (**Uybor.uz Live API**, **OLX.uz**, **Uysot.uz**, **Domtut.uz**, **Tashkent.etagi.com**, **Realt24.uz**, **Joymee.uz**) и экологическими слоями города.

## Запуск
Сайт полностью работает без сборки при прямом открытии `index.html` в браузере (`file://`) — включая прямую подгрузку реальных объявлений с открытого API `https://api.uybor.uz/api/v1/listings`. Для запуска с локальным сервером:
```bash
python server.py
# Откройте http://localhost:8080
```

## Интеграция с Uybor.uz, OLX.uz и другими сайтами недвижимости
- **7 подключённых площадок Узбекистана**: `Uybor.uz` (Live REST API), `OLX.uz`, `Uysot.uz`, `Domtut.uz`, `Tashkent.etagi.com`, `Realt24.uz`, `Joymee.uz`.
- **Прямой Live API `Uybor.uz`**:
  - Прямые запросы из браузера к `https://api.uybor.uz/api/v1/listings` и `https://api.uybor.uz/api/v1/listings/residential-complex` (поддерживают CORS `Access-Control-Allow-Origin: *`).
  - Автоматически загружает реальные квартиры, дома и новостройки (ЖК) Ташкента с точными GPS-координатами (`lat`/`lng`), оригинальными фотографиями, ценами в USD/UZS, этажностью, площадью и прямыми ссылками `https://uybor.uz/ru/listing/{id}`.
  - При вставке любой ссылки вида `https://uybor.uz/ru/listing/1324763` объект мгновенно подтягивается напрямую по ID из `api.uybor.uz/api/v1/listings/{id}`.
- **Прямые поисковые переходы с синхронизацией фильтров**:
  - Под фильтрами расположена панель **«Открыть фильтр на: Uybor · OLX · Uysot · Domtut · Этажи · Realt24 · Joymee»**, которая формирует реальные URL-запросы с учётом выбранного района Ташкента, количества комнат, типа жилья и диапазона цен в `$`.
  - На каждой карточке, в поп-апе на карте и на странице объекта (`property.html`) есть прямые кнопки перехода к объявлению на исходной площадке, а также блок **«Сравнить цены и найти аналоги на площадках недвижимости»**.
- **Умный импорт объявлений по ссылке или тексту (`js/integrations.js`)**:
  - Нажмите **«Uybor · OLX · 7 площадок»** в верхней панели или **«+ Импорт по ссылке»** в фильтрах.
  - Вставьте любую ссылку с `uybor.uz`, `olx.uz`, `realt24.uz`, `uysot.uz`, `domtut.uz`, `joymee.uz`, `tashkent.etagi.com` или скопированный текст объявления из Telegram/OLX.
  - Встроенный **геокодер 60+ ориентиров и кварталов Ташкента** определяет координаты и район, после чего рассчитывает **AQI воздуха, шум в дБ, расстояние до метро/парка и Эко-рейтинг (0–100)** и ставит объект на карту.
- **Выгрузка в Excel (CSV)**: экспорт отфильтрованных объявлений со всеми рассчитанными эко-индексами и ссылками на площадки в `.csv`.
